# 2
Il y aura annuellement six Assises Criminelles Ordinaires.
La première Assise commencera le 3 janvier :
La seconde : le 1er mars ;
La troisième : le 1er mai ;
La quatrième : le 7 juillet ;
La cinquième : le 1er septembre ;
La sixième : le 1er novembre.
Si le jour indiqué pour l’ouverture de l’Assise est un Dimanche ou un jour férié, elle commencera le premier jour ouvrier suivant.
