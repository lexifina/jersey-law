# 31 Priority where security interest transferred
(1) A security interest that is transferred has the same priority as it had immediately before the transfer.
(2) If the same security interest is transferred more than once by the same secured party, priority in the security interest goes -
(a) if a transferee has possession or control of the collateral, to the transferee who has possession or control of the collateral; or
(b) if no transferee has possession or control of the collateral, to the transferee whose transfer is the transfer in relation to which a financing statement or financing change statement was first registered.
