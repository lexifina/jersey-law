# 18A Classification changes
Where a classification change is made -
(a) any adjustment resulting from that change has effect from -
(i) the first day of the month in which there first occurred the circumstances giving rise to the change, or
(ii) if in any case the determining officer is satisfied there is good cause to set a later date for the adjustment to have effect, that later date; and
(b) Articles 17 to 19 of the Social Security (Contributions) (Jersey) Order 1975 apply in relation to any contributions paid following the day on which the change has effect, where such contributions were, within the meaning of those Articles, paid in error or in excess.
