# 3 Use classes
(1) Planning permission is hereby granted by the Minister where a building or other land is used for a purpose specified in a use Class set out in Schedule 2 to use the building or land for another purpose specified in that use Class.
(2) A use which is ordinarily incidental to and included in a use set out in Schedule 2 is not excluded from that use as an incident of that use merely by reason of its specification in that Schedule as a separate use.
(3) A use which is not specified in a use class set out in Schedule 2 shall require planning permission.
