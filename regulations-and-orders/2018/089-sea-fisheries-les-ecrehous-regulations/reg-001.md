# 1 Interpretation
In these Regulations -
“Les Ecréhous” means the area -
(a) that is bounded by straight lines drawn in the sequences set out in Columns 1 and 2 of the table set out in the Schedule, as determined in accordance with the World Geodetic System 1984; and
(b) depicted in the chartlet set out in the Schedule;
“parlour pot” means any pot, container or item whatsoever which is designed, adapted or intended to be used, or which is capable of being used, for the taking of crustaceans and which is a double-chambered pot, container or item, with the second chamber known as the parlour from which escape is restricted.
